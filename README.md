# 🤖 ربات‌ساز روبیکا ✦ استودیو — نسخه ۲

استودیوی کامل ساخت و مدیریت ربات روبیکا: بک‌اند FastAPI + فرانت‌اند تک‌فایل fashion.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 🔗 اتصال چندرباته | اتصال با توکن + بررسی `getMe` + پولینگ `getUpdates` (یک تسک جدا برای هر ربات) |
| 💬 پاسخ‌ها | پیام `/start`، پاسخ پیش‌فرض، پاسخ دستور ناشناخته، `help/` خودکار، تأخیر انسانی |
| ⌨️ دستورات | دستورات سفارشی نامحدود (`/about` و…) |
| 🔎 کلیدواژه‌ها | پاسخ خودکار با ۳ حالت تطبیق: شامل / دقیق / شروع با |
| 🔘 دکمه‌ها | کیبورد معمولی (`chat_keypad`) + دکمه شیشه‌ای (`inline_keypad`) با فرمت رسمی روبیکا |
| 👥 کاربران | لیست چت‌ها، آمار هر کاربر، بلاک/آنبلاک |
| 📣 ارسال | ارسال تکی به `chat_id` + پیام همگانی به همه کاربران |
| 📡 مانیتور زنده | آمار لحظه‌ای (SSE) + لاگ ربات + پیام‌های اخیر و پاسخ‌ها |
| 💾 بکاپ | خروجی/ورودی JSON همه تنظیمات |
| 💾 ماندگاری | ذخیره خودکار در `bots_data.json` + ادامه پولینگ بعد از ری‌استارت |
| 🎨 رابط fashion | تم تیره/روشن، شیشه‌ای، پیش‌نمایش موبایل، کاملاً فارسی و راست‌چین |

## 🚀 اجرای سریع (لوکال)

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

بعد مرورگر را باز کن: **http://localhost:8000** (فرانت‌اند از خود بک‌اند سرو می‌شود).

> اگر `index.html` را جدا باز کردی (GitHub Pages یا `file://`)، آدرس بک‌اند را در فیلد «آدرس سرور» وارد کن.

## 🐳 داکر

```bash
docker build -t rubika-bot-studio .
docker run -p 8000:8000 -v botdata:/app/data rubika-bot-studio
```

## ⚙️ متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `8000` | پورت سرور |
| `RUBIKA_API_BASE` | `https://botapi.rubika.ir/v1` | بیس API روبیکا |
| `CORS_ORIGINS` | `*` | دامنه‌های مجاز (در محصول واقعی محدود کن) |
| `DATA_FILE` | `./bots_data.json` | مسیر ذخیره تنظیمات |
| `POLL_INTERVAL` | `0.6` | فاصله پولینگ (ثانیه) |
| `LOG_LEVEL` | `INFO` | سطح لاگ |

## 📚 API

| متد | مسیر | توضیح |
|---|---|---|
| `GET` | `/` | فرانت‌اند |
| `GET` | `/health` | سلامت + نسخه + آپتایم |
| `POST` | `/connect` | اتصال `{token}` |
| `POST` | `/disconnect` | قطع اتصال |
| `GET` | `/bots` | لیست ربات‌ها |
| `GET` | `/bot?token=` | کانفیگ کامل یک ربات |
| `POST` | `/config` | ذخیره تنظیمات (پارشیال) |
| `POST` | `/toggle` | فعال/غیرفعال |
| `POST` | `/send` | ارسال تکی `{token, chat_id, text}` |
| `POST` | `/broadcast` | همگانی `{token, text}` |
| `GET` | `/stats?token=` | آمار (بدون توکن = کلی) |
| `GET` | `/chats?token=` | کاربران |
| `GET` | `/recent?token=` | پیام‌های اخیر |
| `GET` | `/logs?token=` | لاگ ربات |
| `DELETE` | `/logs?token=` | پاک کردن لاگ |
| `POST` | `/block` | بلاک/آنبلاک `{token, chat_id, blocked}` |
| `POST` | `/export` | خروجی JSON |
| `POST` | `/import` | ورودی JSON |
| `GET` | `/events?token=` | استریم زنده (SSE) |
| `GET` | `/docs` | مستندات تعاملی FastAPI |

## 🐞 باگ‌های رفع‌شده از نسخه ۱

- ❌➡️✅ فایل `main.py` با fence مارک‌داون (` ```python `) شروع می‌شد و اصلاً اجرا نمی‌شد (SyntaxError).
- ❌➡️✅ خطاهای اعتبارسنجی انگلیسی و خام (422) بودند → حالا فارسی و تمیز (400).
- ❌➡️✅ توکن کامل در لاگ چاپ می‌شد → حالا mask می‌شود (`***xxxxxx`).
- ❌➡️✅ با ری‌استارت سرور همه ربات‌ها می‌پریدند → حالا ذخیره فایلی + resume خودکار.
- ❌➡️✅ فقط `/start` و fallback پشتیبانی می‌شد → دستورات، کلیدواژه، دکمه، بلاک، آمار، لاگ…
- ❌➡️✅ فرانت‌اند آدرس هاردکد Render داشت → حالا origin جاری را خودش تشخیص می‌دهد.
- ❌➡️✅ `Dockerfile` فقط `main.py` را کپی می‌کرد → حالا `index.html` هم + healthcheck + volume دیتا.
- ❌➡️✅ `README` به پوشه‌های `backend/` و `frontend/` اشاره می‌کرد که وجود نداشتند.
